FOR DEEKSHA - WEBSITE PROJECT

Files:
- index.html: website structure
- style.css: visual design and responsive layout
- script.js: menu, photo lightbox, product category filters, wishlist and surprise button
- images/deeksha-1.jpeg and images/deeksha-2.jpeg: uploaded photos

HOW TO RUN:
1. Extract this ZIP.
2. Keep the images folder in the same folder as index.html.
3. Open index.html in a browser, or open the folder in Windsurf / VS Code.
4. For a public website link, publish the folder using Netlify Drop or GitHub Pages.

NOTE:
The jewelry cards are decorative gift ideas, not a real checkout or online store. Wishlist works in the current browser session and does not require a database. Google Fonts need an internet connection; fallback fonts are included.
